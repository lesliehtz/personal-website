# Leslie Heintz Photography Portfolio

> 🚧 **Work in Progress** - This portfolio site is currently under active development.

A personal photography portfolio website showcasing my photography work.

## 🛠️ Tech Stack

- **Framework**: [Astro 5.0](https://astro.build) - Static site generator optimized for content-focused websites
- **Content Management**: Astro Content Collections with markdown frontmatter
- **Image Processing**: Sharp (WebP/AVIF conversion)
- **Styling**: Plain CSS with custom properties
- **Fonts**:
  - Inter
  - Inconsolata
- **Deployment**: GitHub Pages (via GitHub Actions)

## 📸 Images

Images are automatically optimized with:
- Multiple responsive breakpoints (640px - 2048px)
- Lazy loading below the fold
- Smart layout: portrait images paired in two-column rows, landscape images full-width
